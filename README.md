The City Map (Grand Plaza)

AGEx is not a website.
It is a digital city-state built to orient, train, and initiate stewards into an integrated ecosystem of law, learning, capital, experimentation, and provision.

This repository contains the AGEx City Map — the Grand Plaza from which all districts of the ecosystem are accessed and understood.

Purpose of the City Map

The City Map serves three functions:

Orientation
Visitors are not shown links; they are introduced to a living system.
Each district represents a pillar ofstewardship with a clear role and boundary.

Initiation
Through guided interaction, the visitor is led first to understanding (The Charter), then to exploration (the districts), and finally to commitment (the Stewardship Gate).

Cohesion
This plaza unifies multiple independent projects into a single narrative and navigational framework.
The Districts

Each district is a sovereign domain with its own function:

🏛️ The Charter District
The constitution of stewardship — law before labor, doctrine before expansion.

🦈 The Financial District
The public gate into disciplined capital. Entry here precedes access to the inner Lodge.

🧠 The Academy
Formation of the mind — discipline, thinking, and responsibility.

⚗️ The Lab
Sanctioned experimentation — testing models, refining systems, forging tools.

📦 The Provisions
Durable resources for builders, not consumers.
All districts link outward to their respective sites while remaining constitutionally anchored to The Steward’s Charter.

The Stewardship Gate

Access to deeper participation is not assumed.

A persistent “Apply for Stewardship” gate is present across the experience and links to a formal application process.
This reinforces the principle that AGEx is built for builders, not spectators.
Technical Philosophy

Foundation-first: No framework dependency required; designed to run cleanly on GitHub Pages.

Single source of truth: All district routing and copy are controlled via config.js.

Progressive activation: Static clarity first, interactivity second, refinement last.

Mobile sovereignty: Designed mobile-first; desktop is an expansion, not a requirement.
